# 수식 이미지와 Word 선택 영역 서식 연동

2026-11-08. 기준 `393efa2`(PR #41 후 문서 정리). 구현 계획 3단계 후속이다.

## 동작

‘모두 그림’에서 수식 그림 크기·색의 출처를 선택한다.

- **직접 지정**: 기존 6–36pt/0.5pt·RGB 입력값. 기본 11pt·검정과 기존 캐시 키를 유지한다.
- **적용할 Word 선택 영역에서 가져오기**: 명시적으로 적용할 때 `Range.font.size/color`를 읽어 해당 적용의 수식 이미지 프로필로 사용한다. 원본 LaTeX는 바꾸지 않는다. 출처를 바꿔도 직접 지정 값은 유지한다.

선택 영역 전체의 크기·색이 통일되어야 한다. 혼합/미확정 값, 지원 범위 밖 크기, RGB로 확정되지 않은 색은 적용 전 거부하고 직접 지정을 안내한다. 임의의 첫 문단/기본값으로 대체하지 않는다. 문단별 서식을 추적하거나 선택 이동에 따라 문서를 수정하는 기능은 아니다. Word 수식 우선 모드는 이 옵션을 사용하지 않는다. TeX에 명시한 색 명령은 그대로이며 선택한 색은 기본색이다.

Word 전용 표현은 Word 개체로 보존한다. 표 안 수식·그림처럼 복합 원본으로 보존한 개체는 새 이미지 설정으로 내부를 다시 그리지 않는다. 편집할 수 있는 MD 수식이 없으면 선택 영역 서식도 읽지 않는다.

## 글꼴 선택의 경계와 다음 작업

현재 MathJax 3.2.2 SVG는 자체 TeX 글리프 경로와 메트릭을 쓴다. `font-family`를 Word 글꼴 이름으로 바꾸어도 해당 경로는 바뀌지 않는다. [MathJax 3.2 공식 글꼴 설명](https://docs.mathjax.org/en/v3.2/output/fonts.html)은 TeX 글꼴 지원과 별도 메트릭 데이터의 필요성을 설명한다. 그러므로 문서 글꼴을 선택한 것처럼 보이는 옵션은 추가하지 않았다.

Word 글꼴 자체 선택은 아직 완료하지 않은 3단계 항목이다. 다음 렌더러 검토는 수학 글꼴의 글리프/메트릭을 실제로 바꾸는 경로인지 먼저 확인하고, `align`/`aligned`의 정렬·기준선·한글 텍스트·큰 연산자·반복 렌더 격리·오프라인 패키징을 비교해야 한다. 임의 본문 글꼴에는 수학 글리프가 없을 수 있으므로 지원 글꼴 범위와 누락 시 정책도 먼저 정한다. 기존 정렬 문제를 일으켰던 중간 TeX→MathML 경로로 단순 회귀하지 않는다. 문서 서식의 지속 추적과 본문 자동 전환은 연결하지 않았다.
