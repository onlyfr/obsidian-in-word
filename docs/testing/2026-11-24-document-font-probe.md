# Word 문서 글꼴로 수식 그림 그리기 — 2026-11-24

Windows 데스크톱 Word의 합성 문서에서 선택 영역의 글꼴을 변경하고 Office.js로 이름을 다시 읽었다. Temml이 만든 MathML을 작업창에서 배치한 뒤 SVG foreignObject와 캔버스로 그렸다. 20 CSS px에서 세 글꼴에 숫자, 변수, 합 기호·첨자, 두 줄 aligned, 빈 좌변과 추가 &가 있는 세 줄 align을 각각 적용했다.

| Word 글꼴 | 숫자 123 너비(px) | 세 줄 align 너비(px) | 세 등호 간 가로 위치 차이(px) |
| --- | ---: | ---: | ---: |
| Cambria Math | 33.23 | 199.92 | 0 |
| Arial | 33.38 | 193.39 | 0 |
| Times New Roman | 30.00 | 192.58 | 0 |

숫자 이미지의 픽셀 해시는 세 글꼴에서 달랐다. 반면 수학 이탤릭 변수 x의 픽셀은 세 경우 모두 같았다. 브라우저의 대체 글꼴 사용과 일치하는 결과이며, 이 측정으로 실제 사용된 글꼴 파일까지 식별할 수는 없다. 합과 첨자의 기준선도 글꼴에 따라 달랐다. 독립된 그림에서는 align의 페이지 너비 기준 여백을 제거해야 했다. 초기 측정에서 2320px였던 Cambria Math 표가 여백 처리 후 199.92px로 줄었다. 등호 좌표는 작업창 레이아웃에서 측정했다.

Cambria Math로 그린 합 수식 PNG를 테스트 문서에 삽입한 뒤 앱의 수식 표지를 통해 MD로 읽어 원본 TeX가 일치함을 확인했다. 이 검사는 Word 본문의 시각적 기준선, 장문 수식의 잘림, 프로필별 캐시 분리 및 저장·재열기 검사를 대체하지 않는다.

다음 구현은 모든 글리프가 문서 글꼴과 같다고 약속하는 대신, 문서 글꼴을 우선하고 없는 수학 글리프에는 수학 글꼴을 사용하는 선택지를 대상으로 한다. 출시 전 Word 배치 기준선, 긴 align의 최종 PNG, 프로필별 캐시 및 재열기를 검증한다. 사용자가 선택하지 않으면 기존 MathJax TeX 경로를 사용한다.

재현 명령은 `npm run test:word -- --document-font-probe`이며, 측정값과 픽셀 해시는 해당 실행 폴더의 `document-font.json`에 저장된다.
