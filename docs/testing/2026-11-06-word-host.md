## 재현과 증거

사전 조건과 실행 방법은 [시험 도구 설명](../../scripts/word-host/README.md)에 있다. Windows에서 Word를 닫은 상태로 `npm run test:word`를 실행한다. 이번 재현 실행 디렉터리는 `test-docs/word-host/20261106-190456-c14771`이다. 이 디렉터리는 gitignore 대상이며 다음을 보존한다.

- `results.jsonl`: 실제 Office.js 유즈 케이스 결과·스냅샷·실행 시간
- `com-results.jsonl`: COM의 실행 취소 단계별 텍스트/객체 수 검증
- `summary.json`, `report.md`: 요약
- `acceptance.docx`, `manifest.xml`, `server.log`, `word.log`: 시험 문서·임시 매니페스트·진단 로그

실패 주입은 Office.js 메서드 인자/스타일 setter를 잠시 가로채 실제 Word에 잘못된 OOXML/존재하지 않는 스타일을 보낸다. 호출 자체를 모의 성공/실패로 대체하지 않는다. 모든 가로채기는 `finally`에서 복원한다. 스타일 이름을 HTML에 그대로 넣으면 Word가 새 스타일을 만들 수도 있어, 스타일 setter에서만 실패를 주입한다.

실행 취소 검증은 본문 텍스트와 표·도형·수식 수 기준이며 모든 서식·관계·OOXML 바이트의 동일성을 보증하지 않는다. 이 문서의 실패 위치와 Word 빌드에서 확인한 결과다. 다른 실패 위치, Mac/웹 Word, 임의 사용자 문서는 별도 검증 대상이다.

전체 명령의 18개 단계와 자동 정리가 통과했고, 종료 후 Word 프로세스와 시험 서버가 남지 않았으며 기존 운영 매니페스트 등록은 유지됐다. 기존 단위 테스트 372개, 타입체크·빌드도 통과했다. 제품 코드 추가 변경은 없다.
