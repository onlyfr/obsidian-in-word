# 2026-11-24 저장소 점검 및 Windows Word 회귀 검증

## 수정 사항

- Windows 내장 다운로드의 30초 제한이 HTTP 응답 헤더 수신 뒤 해제됐다. 이제 상태 응답의 JSON 해석과 파일 본문 읽기가 끝날 때까지 제한을 유지한다. 헤더는 도착하지만 파일 본문이 끝나지 않는 경우를 자동 테스트에 추가했다.
- Windows 앱 인수 시험에서 Word 종료 명령이 실패하면 임시 애드인 등록과 시험 서버 정리까지 건너뛸 수 있었다. 종료 결과와 별도로 정리를 시도하며, 등록 경로가 이번 시험의 문서와 일치할 때만 해당 값을 제거한다.
- TypeScript의 미사용 선언 검사에서 확인된 제품·테스트 코드 5곳을 정리했다.

재현 명령은 `npm test`, `npm run build`, `npm run test:word`와 개별 옵션 `--partial-only`, `--document-font-probe`, `--community-only`, `--transfer-only`, `--body-check-only`이다. 이관 대상 쪽은 `python scripts/windows-host/run.py --transfer-source <transfer-summary.json 경로>`로 확인했다.

별도 Windows 사용자에서의 첫 설치·신뢰 취소·해제 시험은 기존 합의대로 보류했다. 이번 점검에서는 실제 키보드를 통한 IME 입력과 여러 사용자의 동시 공동 편집을 재측정하지 않았다. npm audit 결과는 해당 시점에 등록된 패키지 권고 범위다.
