# LaTeX 계열 수식 이미지 글꼴 패치

2026-11-07. 옵션 → 수식 출력 → **모두 그림 (LaTeX 기본 글꼴)** 을 선택하면 새로 적용하는 모든 편집 가능한 LaTeX 수식을 Latin Modern Math로 이미지화한다. 기본 Word 수식 우선 옵션은 유지한다. 이 경로에서 이미지로 대체되는 수식도 같은 글꼴을 사용하지만, OMML은 Word 수식으로 남으므로 문서 전체를 같은 글꼴로 맞추려면 모두 그림 선택이 필요하다. 원본 보존 블록 속 불투명 개체는 기존 정책대로 유지한다.

## 변경

- CTAN의 Latin Modern Math 1.959 원본 OTF와 GUST 라이선스·저자·manifest 정보를 저장소에 포함.
- 이미지 모듈에서만 지연 로딩. 라이브 측정 전에 FontFace 로딩을 완료하고, 동일한 바이트를 SVG 안에도 data URL로 삽입. 외부 글꼴 설치/CDN은 필요하지 않다.
- 글꼴 로딩 실패 시 다른 글꼴로 조용히 대체하지 않고 기존 수식 소스 보존/경고 경로 사용.
- 이미지 렌더 버전을 1→2로 올려 이전 Cambria 캐시를 재사용하지 않는다. 이미 문서에 들어 있는 그림은 불러오기·적용 시 갱신되며 패치만으로 문서를 자동 수정하지 않는다.
- 고정 11pt·검정·투명 배경·3배 해상도 정책 유지. 문서 글꼴/크기/색 선택은 후속 작업이다.

## 검증

- 단위 테스트 **522건** 통과, 타입체크·빌드 통과.
- 실제 Word `16.0.20527.20150`: `npm run test:word -- --math-only` 통과.
- 증거: `test-docs/word-host/20261107-195447-feb6c5/math-summary.json`.
- 인라인/블록 12종 래스터화, 내장 FontFace 로딩 완료 확인, 적분·합·분수·근호 이미지 육안 확인.
- Word 수식 우선(OMML 2 + 이미지 1) → 모두 그림(OMML 0 + 이미지 3) → Word 수식 우선 복귀. LaTeX/블록 플래그 왕복 및 변경 없는 재적용 시 이미지 바이트 유지.
- 본문 메인 JS는 361.41 kB / gzip 117.92 kB 유지. OTF 내장으로 수식 래스터 지연 청크는 약 981.74 kB / gzip 590.89 kB가 되며 Vite 크기 안내가 발생한다. 글꼴을 처음 이미지화할 때만 내려받는다.

글꼴 출처: https://ctan.org/pkg/lm-math. 배포 라이선스와 원본 파일 정보는 `src/assets/latin-modern-math/`에 기록했다.
