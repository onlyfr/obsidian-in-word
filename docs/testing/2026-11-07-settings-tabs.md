# 옵션 / 커뮤니티 플러그인 설정 탭 (2026-11-07)

## 구현

상단 설정 버튼에서 native HTML dialog를 열고 옵션 / 커뮤니티 플러그인 탭을 제공한다. 좌우 방향키, Home/End, Esc, 닫기와 열기 버튼으로의 포커스 복귀를 연결했다. 320×640 작업창 크기에서 대화상자가 가로로 넘치지 않는 것을 브라우저 DOM 측정과 화면으로 확인했다.

옵션 탭에는 기존 수식 출력 선택(Word 수식 우선 / 모두 그림)과 작업창 에디터 줄 번호·자동 줄바꿈·글자 크기(12/14/16/18/20px)를 둔다. 기존 수식 출력 저장 키를 유지한다. 에디터 옵션은 별도 저장 키로 보관하고 CodeMirror compartment를 재구성하므로 문서 내용·편집기 인스턴스를 바꾸지 않는다. Word 문서 자체의 글꼴/크기를 바꾸는 기능은 아니다. 변환 중에는 옵션 입력을 잠근다.

기존 플러그인 파일 불러오기, 켜기/끄기/삭제, 명령과 개별 설정을 커뮤니티 탭으로 옮겼다. 플러그인의 openTabById 명령도 해당 탭과 설정 창을 연다. 창을 닫으면 PluginSettingTab.hide를 호출하고 개별 설정 DOM을 정리한다. 초기화가 끝날 때까지 파일 선택을 비활성화하고 명령이 없을 때는 명령 선택/실행을 비활성화한다. 기존 번들/설정 저장소는 유지한다.

## 검증

- 단위 테스트 502개, 타입체크와 빌드 통과. 탭 키보드 이동/포커스, 에디터 내용 유지, 저장된 옵션 복원, 잘못된 저장 값과 저장소 차단, 변환 중 옵션 잠금을 포함한다.
- 실제 Word 16.0.20527.20112: `test-docs/word-host/20261107-005500-6de8ed/settings-ui-summary.json` 통과.
- 이 시험은 실제 작업창의 HTML/모듈을 Word WebView에 로드하고 native dialog, 탭 키보드 이벤트, 수식 출력 저장, 줄 번호/줄바꿈 전환, 실제 18px 적용을 확인했다.
- 합성 플러그인의 manifest/main 파일을 파일 입력으로 불러오고 확인 UI를 거쳐, 플러그인 명령으로 개별 설정을 열었다. 설정 창 닫기에서 hide 호출·DOM 정리·포커스 복귀, 플러그인 끄기/다시 켜기/삭제도 확인했다.
- 설정 조작 전후 Word 문단·표·수식이 같았다. 실제 키보드 입력은 전송하지 않았다. 시험 Word는 종료했다.
- 메인 번들 약 360.39 kB / gzip 117.55 kB. 기존 대비 UI/옵션 코드 약 2 kB가 추가됐고 무거운 언어/변환/플러그인 청크의 지연 로딩은 유지한다.

## 계획 상태

이번 단계는 설정 탭이다. 본문 편집 시작/중지, MD↔Word 자동 전환, 실패·Undo 후 상태 확인의 사용자 UI는 아직 구현 완료로 표시하지 않는다. docs/implementation-plan.md에 0→1→2→3 순서와 완료 조건을 둔다.

특히 현재 네이티브 연결 어댑터는 인증된 시험 RPC이므로 이를 제품 API로 그대로 노출하지 않는다. 본문 1단계에서는 실사용 호스트 주입 경계부터 연결하고, 실제 IME 신호가 없을 때 idle을 가정하지 않는다. 별도 복구 UI/자동 롤백은 만들지 않는다.

수식 그림의 Word 글꼴 / 기본 LaTeX 글꼴 선택은 렌더러·캐시 검증이 필요한 후순위로 체크리스트에 남겼다. 이번 UI에 동작하지 않는 선택지는 추가하지 않았다.
