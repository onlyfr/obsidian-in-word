# 개체 식별 안정화·전체 회귀·최적화

2026-11-08. 기준 `9037419`(PR #40 완료). 구현 계획 3단계의 개체 식별·수동 왕복 안정화와 이미지 크기·색 옵션을 구현했다. 지원 계약은 `docs/object-model.md`. 문서 글꼴 자동 연동은 후속 항목이며 본문 자동 전환은 연결하지 않았다.

## 재현한 원인과 수정

1. 일반 그림과 수식이 같은 문단/목록에 있으면 일반 그림 보존이 블록 전체를 감쌌다. 앞서 추출한 수식 토큰까지 원본 HTML에 숨겨져 개별 선택과 전체 선택이 달라졌다. 수정 전 문단·목록 재현 테스트 모두 실패했고, 일반 그림을 인라인 참조로 분리한 뒤 통과했다.
2. OOXML 스캔이 `w:body` 뒤의 다른 패키지 파트도 읽었다. 헤더/푸터 그림·표와 호환용 fallback을 선택 영역 대응에 섞지 않도록 본문 범위를 제한하고 일반적인 대체 표현의 중복 계산을 제거했다.
3. 수식 포함 표는 완전한 표 패키지로 보존하고 내부 수식 수도 손실 방지 검사에 포함한다. 부분 선택이 주변 표 전체를 가져오지 않도록 Word 범위 비교를 추가했다. 표 재삽입 후 불필요한 빈 문단도 정리했다.
4. HTML/OOXML/사이드카의 원본·표지가 충돌하면 추측하지 않는다. 손상된 메타데이터나 보존하지 못한 그림 바이트는 적용 전에 거부한다. 일반 텍스트·코드 속 표지는 개체로 잘못 해석하지 않는다.

## 옵션

‘모두 그림’의 크기(6–36pt, 0.5pt 단위)·RGB 색 선택과 저장을 추가했다. 출력 프로필을 캐시 키에 포함해 변경된 크기/색에 예전 PNG를 재사용하지 않는다. 기본 프로필은 기존 키·PNG를 유지하고 원본 LaTeX도 바꾸지 않는다. 원본 보존 표/개체는 옵션으로 재생성하지 않는다. 앱 빌드 표시도 추가했다.

## 성능

수식마다 문단 시작을 두 번 역방향 검색하던 경로를 문단 범위 1회 스캔으로 바꿨다. 같은 문단의 OOXML gzip도 수식마다 반복하지 않고 공유·병렬 처리한다.

## 검증

- 단위 **559건**, 타입체크·빌드 통과. 기존 이미지 표지·새 인라인 참조·구형 블록 참조, 텍스트/코드 표지, 손상/충돌, 표·부동 원본 수식 수, 크기/색별 캐시 회귀 포함.
- 실제 Word `16.0.20527.20150` 전체 인수 시험 통과: `test-docs/word-host/20261108-131117-442398/report.md`. 표·수식·부동 도형, 누락 원본 거부, 필수 실패/선택적 스타일 실패, Undo, 오래된 원본 보존, 수식 출력, 서식 왕복, 본문/세션 기존 실험·저장·재열기·Redo·삭제 가드.
- 대형 합성 문서: 300문단·표 30·수식 60, 불러오기 1.950초, 적용 3.505/3.400/3.990초. 세 번 모두 내용·개체 수 유지. 한 시스템의 관찰값이며 이전 날짜의 실행과 직접적인 성능 비교는 하지 않는다.
- 개체 선택 범위 시험: 일반 그림과 수식이 같은 문단·목록, 동일 수식 반복, 수식 이미지/OMML을 포함한 표를 혼합. 개별 그림·문단·전체에서 원본 일치, 표 안 그림 단독 읽기 시 표 전체 미채택. 전체 적용 3회 동안 문단 수·정규화된 문단 텍스트·그림/수식/표 수 유지. 저장·재열기 후 원본/개체 수 유지, 같은 전체 영역 재로드 시 사이드카 Part ID 유지. `test-docs/word-host/20261108-130712-83f3c5/identity-summary.json`.
- 이미지 옵션 실제 PNG 크기 증가와 파란색 픽셀 확인, 기본→18pt/파랑→기본 전환의 원본·개체 수 유지: 같은 identity summary의 `math-appearance`.
- 실제 설정 탭: 크기·색 저장과 images/hybrid 활성·비활성, 기존 플러그인/편집기 옵션 통과. `test-docs/word-host/20261108-125701-6358ae/settings-ui-summary.json`.
- 기본 수식 PNG 18종의 바이트·크기·기준선은 기준판과 동일. `test-docs/word-host/20261108-130012-6fe571/math-summary.json` (`--math-only --compare-raster-ref 9037419`).
- 최종 전체 시험에는 개체 선택 범위·누락된 인라인 그림 원본의 적용 전 거부·크기/색 옵션 검사도 기본 포함했다. 중간에 옵션 시험이 문서 전체 사이드카의 첫 항목을 해당 수식으로 가정해 실패했으나, 원본을 삭제하지 않고 수식·출력 프로필 기준으로 선택하도록 시험을 수정해 통과했다.
- 네이티브 상태 확인·실제 Undo/Redo 유지: `test-docs/word-host/20261108-130125-8abf9e/body-check-summary.json`. 기존 시작/중지·관찰기 종료·등록 중 중지·응답 손실 회귀: `test-docs/word-host/20261108-130235-6b9e48/body-controls-summary.json`. 한 중간 실행은 Word가 전면 창이 아니어서 가드가 중단했고, 조건을 완화하지 않고 재실행해 통과했다. 키 입력은 없었다.
- 최종 메인 JS 약 362.45 kB / gzip 118.27 kB. 기능·검증 보강으로 소폭 증가했다. 수식 이미지 지연 청크 약 1,672 kB / gzip 583 kB이며 큰 청크 안내는 유지된다. 다운로드 크기 축소는 이번 성과가 아니다.

모든 시험은 별도 합성 문서에서 실행했다. Mac/웹 Word·공동 편집·다양한 IME 실제 키보드 입력은 이번에 새로 검증하지 않았다. 문서 글꼴 자동 연동은 계획에 남기며, 자동 전환은 5단계를 유지한다.
