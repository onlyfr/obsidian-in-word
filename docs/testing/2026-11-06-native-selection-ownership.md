# 네이티브 선택 이벤트와 블록 소유권 (2026-11-06)

## 동작과 범위

명시적으로 등록한 일반 문단만 커서 진입 때 마크다운 소스, 이탈 때 Word 서식으로 전환한다. 선택 이벤트는 문단을 등록하지 않는다. Word의 설치된 타입 라이브러리에서 `WindowSelectionChange` 연결 지점을 찾아 구독하며, 콜백은 선택 리비전만 증가시킨다. 실제 대상 조회는 기존 선택 드라이버가 TSF idle에서 수행한다. 상태 불명·조합 중·단절에는 게이트를 닫는다. health 프레임은 선택을 다시 조회하지 않는다.

등록은 네이티브 mode 4 명령으로 수행한다. 문서·메인 스토리·한 문단·원문/OOXML·선택·포커스·관찰 순서·기한을 재확인한 뒤 기존 문단을 rich content control로 감싼다. 텍스트를 다시 쓰지 않고 원래 커서를 복원한다. 문서 Custom XML `urn:obsidian-in-word:body-owners:v1`에 블록 키와 `ContentControl.ID`를 함께 저장한다. 이후 쓰기는 이 결합을 Word UI 스레드에서 확인하며 ID 불일치나 source/rendered 태그 중복을 거부한다.

다른 애드인의 컨트롤, 겹친 컨트롤은 가져오거나 중첩하지 않는다. 현재 렌더러가 보존하지 못하는 직접 색상·크기·문단 배치, 목록·표·필드·개체·변경 추적 등은 등록 전에 거부한다. 기본 문단 스타일은 하드코딩한 Normal만 가정하지 않고 문서의 기본 paragraph style을 찾는다.

등록 직후 커서가 그대로면 Word 선택 이벤트가 오지 않는 경우를 실제 시험에서 발견했다. 등록 성공이 소유권 대상을 바꾼 것이므로 네이티브 선택 리비전을 명시적으로 증가시켜 자동 전환 누락을 해결했다. Windows 테스트 전송의 이전 요청 파일 읽기 잠금도 발견해, 아직 게시되지 않은 요청의 atomic rename만 짧게 재시도한다. 게시된 변경 명령이나 결과가 불확실한 작업은 재실행하지 않는다.

## 실제 Word 검증

Windows Word `16.0.20527.20112`, 독립적인 합성 acceptance.docx와 실행별 등록을 사용했다. 시험이 소유한 Word/관찰기/서버만 종료한다. 키 입력 시험은 사용자가 입력을 멈출 수 있는 시간에 따로 수행했다.

| 소유권·선택 통합 | `test-docs/word-host/20261106-232920-2d2f72/native-selection-summary.json` 전체 통과 |

선택 통합은 두 문단을 명시적으로 등록하고 커서 보존·반복 등록 무변경·미등록 문단 자동 채택 없음·A/B 빠른 이동의 최종 선택·선택 이탈 렌더링·health 프레임 중 조회/변경 루프 없음·이웃/문단 수 유지·다른 애드인 보존을 확인했다. 최초 통합 동안 `Word.run`과 Office.js 선택 구독을 예외 함수로 바꿔 우회 사용을 차단했다. 실제 저장·닫기·재열기 후 소유권이 같은 컨트롤을 가리키고 새 네이티브 이벤트로 소스 진입/이탈하는 것도 확인했다.

ID 변조는 클라이언트 소유권 조회를 우회한 스냅샷으로 네이티브 요청을 직접 보내 결과 12를 확인했다. 같은 태그를 가진 별도 컨트롤 복제는 결과 4로 거부했다. 두 경우 모두 저널을 쓰지 않았다. 시험이 만든 복제 컨트롤만 제거한 뒤 원문이 유지됨을 확인했다. 등록된 B 컨트롤을 삭제하면 텍스트가 남아도 재생성하지 않고 세션을 멈췄다.

기존 통합 시험은 반복 전환 3회, 실행 취소/다시 실행, 저널/내용/태그 뒤 중단, 닫기 실패 복구, 저장·재열기와 이전 epoch 거부, 한글·이모지·코드/커서 보존을 재검증했다. 첫 회귀 시도는 다른 창으로 포커스가 이동해 보호 장치가 중단했으며, 포커스를 갖춘 별도 실행에서 전체 통과했다. 실제 한글 키 입력에서는 조합 중 네이티브 쓰기 거부와 입력 보존을 확인했다. 이 키 입력 경로는 기존 IME/가드 회귀이며, 새 소유권 모드에서 모든 IME를 검증한 것은 아니다.

단위 테스트 484개, 타입체크/프로덕션 빌드, 네이티브 MSVC `/W4 /WX` 빌드가 통과했다. 메인 번들은 358.31 kB / gzip 116.81 kB로 그대로다. 네이티브 개발 모듈과 테스트 RPC는 제품 작업창 번들에 포함하지 않는다.

## 남은 범위와 다음 순서

제품 UI와 독립 설치 앱은 아직 연결하지 않는다. 새로운 `--native-selection-only` 경로만 registry 소유권을 필수로 사용한다. 기존 flow/guard fixture는 이전 태그 프로토콜의 회귀를 위해 명시적 legacy 모드로 실행한다.

등록 도중 COM 실패가 발생하면 컨트롤만 생기거나 소유권 기록만 남을 수 있다. 자동 재시도·자동 채택·메타데이터 삭제로 덮지 않고 명시적 Undo/검토가 필요하다. 삭제된 컨트롤의 레코드는 유지한다. 임의 사용자 문서, 전체 run 서식 보존, 다른 IME, 재진입/통신 단절 경합, 공동 편집은 추가 검증 대상이다.

다음은 원본 run 서식 보존과 재진입·통신 중단 처리를 보강한다. 최종 앱은 npm/개발 서버/GitHub Pages 없이 설치·실행하는 네이티브 형태를 목표로 유지한다.
