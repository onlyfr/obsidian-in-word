# 구현 계획 / 작업 체크리스트

마지막 갱신: 2026-11-08. 체크 표시는 구현과 해당 검증이 끝났을 때만 갱신한다. 실행 중인 작업, 남은 제약과 다음 순서를 여기에 기록한다.

사용자 결정(2026-11-08): **2. 실패·Undo 상태 확인 → 3. 개체 정의·세부 옵션·수동 왕복 안정화 → 4. 후순위 작업 → 5. 본문 자동 전환 연결** 순으로 진행한다. 자동 전환은 마지막이며, 아래 앞 단계의 완료 조건을 충족하기 전에는 연결하지 않는다.

## 원칙

- 현재 Word 본문의 MD 표현 ↔ Word 표현 전환 경험을 중심에 둔다.
- MD→Word 렌더링 품질을 우선하며 Word→MD는 가능한 마크다운 표현을 추출한다.
- 실패 시 자동 편집을 정지하고 Word Undo/Redo를 사용한다. 별도 복구 UI와 자동 롤백은 추가하지 않는다.
- 최종 앱은 npm/개발 서버/GitHub Pages 없이 실행하는 네이티브 형태다. 현재 웹 작업창과 시험 RPC는 중간 검증 환경이다.
