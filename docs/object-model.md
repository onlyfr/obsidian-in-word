# MD / Word 개체 식별·보존 규칙

2026-11-08. 수동 선택 영역 변환의 계약이다. MD/Obsidian으로 표현할 수 있는 내용은 Word로 렌더링하고, Word에서만 가능한 표현은 Word 원본 개체로 남긴다. 개체 안 개체도 이 규칙을 따른다. 본문 자동 전환은 아직 연결하지 않는다.

| 개체 | MD 표현 | 식별 기준 / 적용 정책 |
| --- | --- | --- |
| MD 수식 원본 | `$…$`, `$$…$$` | LaTeX 원본과 인라인/블록 구분이 의미상 원본. 출력 설정에 따라 OMML 또는 이미지로 만든다. |
| Word 네이티브 수식 | 가능한 LaTeX 또는 원본 보존 표지 | 선택 영역 본문의 OMML을 HTML 이미지와 대응시킨다. 지원 범위 밖의 수식은 원본 OOXML을 보존한다. |
| 애드인이 만든 수식 이미지 | 원래 LaTeX | OOXML `wp:docPr`의 `owb:math:<id>[:d]` 표지와 문서 사이드카를 사용한다. 수식처럼 보인다는 이유로 일반 그림을 수식으로 간주하지 않는다. |
| 일반 인라인 그림 | `<!-- word:img id=0123abcd -->` | 이미지 바이트·표현 속성을 보존한 사이드카 참조. 문단·목록 전체를 가리지 않으며 같은 그림이 반복돼도 각 위치를 복원한다. |
| 수식이 든 표 / 복합 Word 개체 | `<!-- word:obj id=… kind=table -->` 등 | 선택에 표 전체가 포함된 경우에만 표 범위의 OOXML 패키지·미디어·스타일을 함께 보존한다. 내부 수식도 원래 개체로 복원하며, 전체 MD에서 표 내부의 개별 수식을 편집하는 기능은 제공하지 않는다. |
| 부동 개체 | 원본 보존 표지 | 위치·도형 등을 포함한 원본 패키지로 복원한다. 같은 보존 블록 안 수식도 함께 보존한다. |

## 원본과 캐시

- 수식 이미지의 전체 원본은 문서 Custom XML Part의 사이드카에 저장한다. 대체 텍스트의 LaTeX는 공백이 정규화되고 길이가 제한된 보조 정보다.
- 사이드카가 없을 때만 잘리지 않은 대체 텍스트로 원본을 읽을 수 있다. `…`로 잘린 원본을 추측하지 않는다.
- HTML/OOXML 이미지 수와 순서가 맞아야 하며, HTML에도 수식 표지가 있으면 ID·인라인/블록·사용 가능한 원본이 서로 일치하는지 검사한다. 사이드카와 표지의 원본/종류가 충돌하면 적용을 거부한다.
- 해시는 인증 수단이 아니다. 같은 ID에 다른 원본이 결합된 경우를 검사하며, 손상된 사이드카·중복 파트의 충돌은 원본을 덮어쓰지 않고 거부한다.
- 렌더 버전과 이미지 크기·색 프로필은 이미지 캐시 ID의 일부다. 출력 프로필이 달라져도 원본 LaTeX의 의미는 유지된다. 기본 11pt·검정은 기존 v4 키를 유지한다.
- 일반 그림은 바이트를 확실히 대응시킨 경우에만 새 인라인 참조로 만든다. 바이트를 보존하지 못한 개체는 `unavailable`로 표시하고 적용을 거부한다. 빈 그림으로 성공 처리하지 않는다.
- Word가 다시 붙이는 임시 파일 이름이나 그림 HTML ID를 영구 개체 식별자로 사용하지 않는다. 예전 블록형 `word:obj kind=image` 표지는 계속 지원한다.
- 코드 안의 표지는 글자 그대로다. Word 본문에서 표지처럼 입력한 일반 텍스트도 이스케이프해 우연히 기존 그림으로 해석되지 않도록 한다.

## 선택 범위

- 개별 그림·문단·목록·전체 영역에서 일반 인라인 수식은 동일한 원본으로 읽혀야 한다. 일반 그림 때문에 주변 수식 토큰을 원본 보존 블록 안에 숨기지 않는다.
- 표 안 그림 하나를 선택했다고 주변 표 전체를 가져오지 않는다. 전체 패키지 보존 전에는 선택 범위가 표 전체를 포함하는지 Word 범위 비교로 확인한다.
- 표 전체 선택은 표를 하나의 보존 개체로 다루며 내부 수식 수를 손실 방지 검사에 포함한다. 이것은 내부 수식이 일반 그림으로 바뀐다는 뜻이 아니다.
- OOXML 스캔은 선택 본문 `w:body` 안으로 제한한다. 뒤쪽 헤더/푸터 파트를 선택 영역 개체 수에 포함하지 않고, 일반적인 `mc:Choice`/`mc:Fallback`의 같은 그림을 중복 계산하지 않는다.
- 대응을 확정할 수 없거나 지원되지 않는 복합 구조는 원본 보존 또는 명시적인 거부/경고 대상이다. 모든 Word 개체를 완벽한 MD로 역변환하는 것을 목표로 하지 않는다.

## 옵션 적용 범위

- 현재 옵션 저장은 앱 출처의 브라우저 저장소 단위다. 문서별 또는 수식별 설정이 아니다. 다음 명시적인 적용부터 사용하며, 설정만 바꿔서는 Word 본문을 수정하지 않는다.
- ‘모두 그림’에서 MathJax TeX 글꼴을 사용한다. 크기는 6–36pt, 0.5pt 단위, 색은 RGB를 선택할 수 있다. 기본은 11pt·검정이다.
- ‘Word 수식 우선’에서는 지원되는 OMML을 유지하고 이미지 대체는 기존 기본 프로필을 사용한다. 이미지 크기·색 입력란은 이 모드에서 비활성화된다.
- 원본 보존 표·부동 개체 안 이미지는 옵션을 바꿔도 개별 재생성하지 않는다. 해당 개체 전체의 원본을 우선한다.
- 크기·색 출처는 직접 지정 또는 다음 적용 시 Word 선택 영역에서 읽기다. 후자는 적용 전 `Range.font`를 읽고 모든 새 이미지에 같은 프로필을 사용한다. 선택 영역에 여러 크기·색이 섞이거나, 값이 미확정/6–36pt 범위 밖/0.5pt 단위가 아니면 본문·사이드카를 바꾸기 전에 중단한다. 별도 선택 이동 관찰기나 지속 추적은 없다.
- 원본 TeX의 명시적인 색 명령은 수식 내용이다. 선택한 RGB는 기본색이며 해당 명령을 지우지 않는다.
- **문서 글꼴로 수식 이미지를 그리는 선택은 아직 제공하지 않는다.** 현재 MathJax 3 SVG는 TeX 경로 글리프를 사용한다. 이름만 바꾸는 설정을 제공하지 않으며 렌더러 검토 경계는 `docs/testing/2026-11-08-math-selection-style.md`에 기록했다.
- 설정의 앱 빌드 표시로 배포판을 확인할 수 있다. 개발 서버는 `local`, Pages 빌드는 배포 커밋 앞 8자다. 열린 작업창과 기존 그림은 배포만으로 자동 갱신되지 않는다.

## 보존·실패 정책

사이드카는 문서 전체가 공유한다. 현재 선택 영역에 없다는 이유로 다른 영역의 원본을 삭제하지 않는다. 변경 없는 재로드는 동등한 OOXML을 재사용해 불필요한 Custom XML Part 재작성을 피한다. 자동 원본 정리는 하지 않아 문서 크기가 늘 수 있다.

필수 복원 요청은 한 번만 실행한다. 실패하면 중단하고 Word Ctrl+Z/Ctrl+Y를 사용한다. 자동 롤백·불확실한 요청 재전송·별도 복구 흐름은 추가하지 않는다. 네이티브 상태 확인은 선택한 소유 문단과 전환 기록에 대한 읽기 전용 검사다.
