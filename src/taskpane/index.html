수식

모든 수식을 Obsidian 스타일의 MathJax TeX 글꼴로 통일하려면 ‘모두 그림’을 선택하세요. 그림도 불러오면 LaTeX로 편집할 수 있습니다. 원본 보존 블록 안의 수식은 제외됩니다.

‘모두 그림’의 다음 적용부터 사용합니다. Word 선택 영역에서 가져오면 적용할 때마다 통일된 크기(6–36pt)·RGB 색을 읽으며, 서식이 섞여 있으면 직접 지정을 안내합니다. 글꼴은 MathJax TeX입니다. 직접 지정의 기본값은 11pt·검정이며, 표 등 원본 보존 개체는 그대로 유지합니다.

작업창 에디터

아래 옵션은 작업창의 마크다운 에디터에 적용됩니다.

플러그인은 불러온 JS 코드를 이 작업창에서 그대로 실행합니다. 신뢰하는 것만 사용하세요. 작업창 에디터 안에서만 동작합니다.

커뮤니티 플러그인 찾기

공식 Obsidian 목록은 바로 검색할 수 있습니다. Windows 앱의 작업창에서는 다운로드가 자동 연결됩니다. GitHub 정식 릴리스를 내려받은 뒤 설치 목록의 ‘켜기’로 적용합니다. Obsidian 전용 API·Node/Electron·보관함 기능은 지원되지 않을 수 있습니다.

목록을 불러와 검색할 수 있습니다.

Windows 앱 / 기존 도우미 연결

Windows 앱 받기 → 압축을 풀고 ObsidianInWord.exe를 실행한 뒤 ‘Word 연결 설정’을 누르세요. Word에서 앱의 작업창을 사용하면 연결 주소가 필요 없습니다. 아래 입력은 기존 다운로드 도우미 사용자용입니다.

도우미 미연결 · 목록 검색은 사용할 수 있습니다.
